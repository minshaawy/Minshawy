❷  التشغيل / How to Run
─────────────────────────────────────────────────

★ الطريقة الأسهل ★ Easiest Method:

  Mac:        دبل-كليك على  start-mac-linux.command
  Windows:    دبل-كليك على  start-windows.bat
  Linux:      دبل-كليك على  start-mac-linux.command

  هيفتح Terminal/CMD ويفتح المتصفح تلقائياً.
  A terminal will open and the browser will launch
  automatically at http://localhost:8000


❸  لو ما اشتغلش / If It Doesn't Work
─────────────────────────────────────────────────

   1. تأكد إن Python مثبت على جهازك
      Make sure Python is installed:
      https://www.python.org/downloads/

   2. على ويندوز: عند تثبيت Python فعّل
      "Add Python to PATH"
      During Windows install: check "Add Python to PATH"

   3. لإيقاف الخادم: Ctrl+C في النافذة
      To stop server: Ctrl+C in the terminal window


❹  مهم جداً / Important
─────────────────────────────────────────────────

  ⚠ لا تفتح index.html بدبل-كليك مباشرة
    Do NOT open index.html with double-click directly

    المتصفحات تمنع تشغيل ملفات MP3 المحلية إلا
    من خلال خادم محلي (لأسباب أمنية).
    Browsers block local MP3 playback unless served
    via a local server (security restriction).
